## 归档原则

1. 每份分析写明日期、数据截止时间和持仓口径。
2. 事实、推测与条件化交易计划分开。
3. 技术分析优先使用5日、55日、233日均线，并进行多周期交叉验证。
4. 同时记录海外映射、行业周期、公司基本面与组合风险。
5. 后续报告继续按 `analyses/YYYY/MM/` 保存并更新本索引。
